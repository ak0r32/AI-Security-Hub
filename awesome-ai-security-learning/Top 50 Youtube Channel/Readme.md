# 🗺️ 6-Month AI Engineering Learning Roadmap

## Month 1: Mathematics & Machine Learning Fundamentals
- Linear Algebra
- Probability and Statistics
- Python for Data Science
- Supervised Learning
- Unsupervised Learning
- Regression and Classification

**Recommended Channels:** StatQuest, 3Blue1Brown, CampusX

## Month 2: Applied Machine Learning
- NumPy and Pandas
- Scikit-learn
- Feature Engineering
- Model Evaluation
- Hyperparameter Tuning
- End-to-End ML Projects

**Recommended Channels:** Krish Naik, codebasics, sentdex

## Month 3: Deep Learning
- Neural Networks
- Backpropagation
- PyTorch
- CNNs and RNNs
- Attention Mechanism
- Transformers

**Recommended Channels:** Andrej Karpathy, DeepLearning.AI, Umar Jamil

## Month 4: Generative AI & LLM Engineering
- LLM Architecture
- Tokenization
- Embeddings
- Vector Databases
- Retrieval-Augmented Generation (RAG)
- Prompt Engineering
- LLM Evaluation

**Recommended Channels:** Hugging Face, James Briggs, LangChain

## Month 5: AI Agents & Agentic Systems
- LangChain
- LangGraph
- Tool Calling
- Agent Memory
- Multi-Agent Systems
- Workflow Automation

**Recommended Channels:** Sam Witteveen, Cole Medin, AI Jason

## Month 6: Production AI Engineering
- Model Deployment
- FastAPI
- Docker
- MLOps
- LLMOps
- Model Monitoring
- AI Evaluation
- Production Optimization

**Recommended Channels:** Full Stack Deep Learning, Chip Huyen, Weights & Biases
